## <Text zh="生成完整主题 CSS" en="Generate theme CSS" />

<DocParagraph>
  <Text
    zh="将输出保存为 okramp-theme.css，在 TDesign 默认样式之后加载。CSS 包含品牌、中性色阶和引用它们的语义变量。"
    en="Save the output as okramp-theme.css and load it after TDesign styles. It includes brand and neutral primitives and semantic variable references."
  />
</DocParagraph>

```ts
import { generateColorTheme } from '@okramp/core';
import { createTDesignCss } from '@okramp/tdesign';

const result = generateColorTheme('#0052D9', {
  mode: 'both',
  contrastPolicy: 'adjust',
});
const css = createTDesignCss(result);
```

## <Text zh="加载与切换" en="Load and switch" />

<DocParagraph>
  <Text
    zh="浅色使用默认根节点，深色设置 theme-mode 属性。切换属性会同时更新语义变量，无需重新生成色阶。"
    en="Light uses the default root; dark uses the theme-mode attribute. Switching updates semantic variables without regenerating scales."
  />
</DocParagraph>

```ts
import 'tdesign-react/dist/tdesign.css';
import './okramp-theme.css';

document.documentElement.setAttribute('theme-mode', 'dark');
// Light mode
document.documentElement.removeAttribute('theme-mode');
```

## <Text zh="CSS 与变量对象" en="CSS and token objects" />

<DocParagraph>
  <Text
    zh="createTDesignCss(result) 返回可保存的 CSS。createTDesignTokens(result) 返回 light、dark 变量对象，适合运行时注入；仅使用实际生成的模式。"
    en="createTDesignCss(result) returns CSS. createTDesignTokens(result) returns light and dark token objects for runtime injection; use a generated mode."
  />
</DocParagraph>

```ts
import { createTDesignTokens } from '@okramp/tdesign';
const tokens = createTDesignTokens(result);
for (const [key, value] of Object.entries(tokens.light)) {
  document.documentElement.style.setProperty(key, value);
}
```
